# Week 3 Moodle PDF

Typst sources for the Assignment 3 Moodle submission PDF.

## Compile

```bash
typst compile src/when2meet/reports/week3/pdf/week3-report.typ \
  src/when2meet/reports/week3/pdf/week3-report.pdf \
  --root src/when2meet/reports/week3
```

Update `data/submission.yaml` with the submission commit hash before compiling.
