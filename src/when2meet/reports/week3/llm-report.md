# LLM Usage Report — Week 3

## Summary

During Week 3 we used AI/LLM tools **only** for:

1. **Speech-to-text** via [speech2text.ru](https://speech2text.ru/) on the Sprint Review recording.
2. **Translation** of meeting notes into English for [customer-review-transcript.md](customer-review-transcript.md) and [customer-review-summary.md](customer-review-summary.md).
