# LLM Usage Report

## Summary

During Week 2 we used AI/LLM tools **only** for:

1. **Translating** meeting-related text into English (raw notes and discussion content).
2. **Speech-to-text** via [speech2text.ru](https://speech2text.ru/) to produce the raw meeting recording transcript.

No LLM was used for implementing MVP v0 backend code, writing user stories, prioritization decisions, Figma design, deployment, or customer-facing product logic.

## Tools

| Tool | Purpose |
| --- | --- |
| [speech2text.ru](https://speech2text.ru/) | Transcribe the customer meeting recording into Russian text |
| LLM translation (tool not fixed to a single vendor) | Translate transcribed meeting content into English for [customer-meeting-transcript.md](customer-meeting-transcript.md) |

## What was produced without LLM assistance

- User stories and MoSCoW priorities in [user-stories.md](user-stories.md)
- FastAPI MVP v0 service, MongoDB models, and pytest tests
- Figma mobile prototype by [PoweredDeveloper](https://github.com/PoweredDeveloper)
- Frontend deployment at [https://pre.innohassle.ru/when-to-meet](https://pre.innohassle.ru/when-to-meet)
- OpenAPI specification, Postman collection, and interface documentation
- Week 2 analysis, meeting summary, and repository report structure written by the team

## Review

English transcript and summary were checked against the recording and team notes before inclusion in the repository.
